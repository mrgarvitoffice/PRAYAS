# **App Name**: Prayas News Terminal

## Core Features:

- News Aggregation: Aggregate news from multiple APIs (NewsData.io, NewsAPI, GNews) and custom scrapers.
- Hierarchical Filtering: Filter news by World/India → State → City with live updates.
- Smart Summary Generation: Generate concise heading + 2–4 bullet points for each article using an summarization tool.
- Text-to-Speech (TTS): Read news summaries (headline + key points) using natural voices with SSML support for prosody, emphasis, and pauses.
- Podcast Generation: Compile multiple news items into a podcast episode (add intro/outro, reorder), export as mp3, and generate an RSS feed.
- Language Support: Enable dual-language support (English + Hindi) for UI, content, TTS, and podcasting.
- Theme Switching: Switch between light and dark themes.

## Style Guidelines:

- Primary color: Indigo (#4F46E5) for a sophisticated, trustworthy feel.
- Background color: Light gray (#F9FAFB) for light mode, dark navy (#1E293B) for dark mode.
- Accent color: Teal (#14B8A6) for highlights and interactive elements, providing a sense of clarity and calm.
- Headline font: 'Space Grotesk' sans-serif for headlines.
- Body font: 'Inter' sans-serif for body text.
- Use minimalist, line-based icons for a clean and modern look.
- Subtle transitions and animations for filter updates and TTS playback.
